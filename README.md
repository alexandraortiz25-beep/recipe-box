# Recipe Box

A simple recipe application built with HTML,
Bootstrap 5.3.3, and JavaScript.

## Features

- Search for recipes using GET.
- Add a new dish using POST.
- Display recipe name, cuisine, and preparation time.
- Handle loading messages and errors.
- Validate empty input fields.

## Technologies

- HTML
- Bootstrap 5.3.3
- JavaScript
- DummyJSON API

## Endpoints

- GET https://dummyjson.com/recipes/{id}
- Gets one recipe.

- POST https://dummyjson.com/recipes/add
- Adds a dish using the practice API.
- The practice server does not really save it.
